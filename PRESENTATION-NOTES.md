# Presentation notes (not part of the system)
How the interface covers the project objectives. These do not appear anywhere in the app.
1. Role-based access control: five roles with separate sign-up/sign-in, role-gated workspaces, blocked actions are logged ("Try a blocked action").
2. AI anomaly detection: risk scoring on every event (late-night issuance, bursts, repeated fake lookups, duplicates), findings, held-for-review credentials, regulator audit dashboards.
3. Decentralized storage with cryptographic hashing: SHA-256 credential codes, chained ledger blocks, IPFS-style identifiers, seals derived from the hash.
4. Immutable verification and privacy compliance: verification reports, owner-controlled access, erasure of the private file, revocation visible to all verifiers.
5. Performance, scalability and cost versus centralized systems: quotas and plans, paginated tables, backend connection table; replace the prototype figures with measured results once the backend exists.
